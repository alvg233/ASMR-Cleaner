# Claude Code 使用指南（写给新手）

> 这是和 AI 结对编程一个完整项目后的经验总结。教你下次自己怎么用。

---

## 核心原则：你把 AI 当什么？

### 最蠢的用法（别这样）
```
你："帮我写个音频处理软件"
AI：哗啦啦输出 2000 行代码
你：看不懂，跑不起来，放弃
```

### 正确的用法（这个项目就是这样做的）
```
你："我想做一个切除 ASMR 静音的工具，先写项目文档和头脑风暴"
AI：帮你梳理需求，问关键问题，确认方案
你："方案定了，帮我写实现计划"
AI：拆成 14 个小任务，每个任务要做什么、改哪个文件、接口是什么
你："一个一个来，先做任务 1"
AI：写代码、验证、提交。出问题了你反馈，AI 修。
```

**核心区别**：不是"给我成品"，而是"一步一步来，每步都看懂"。

## 和 AI 说话怎么表达？四句模板

### 模板 1：说清楚"要什么"+"给什么"+"不要什么"
```
❌ "做个音频处理"
✅ "做一个 Python 音频处理工具，输入 WAV/MP3，切除大于 5 秒的静音段，
    拼接处加 30ms 淡入淡出，输出无损 FLAC。不需要视频处理，不需要 AI 降噪。"
```

### 模板 2：把决策权交给 AI，但你要给方向
```
❌ "怎么选库？"
✅ "用哪个音频库好？要求：轻量、支持 MP3/FLAC、适合单文件打包。pydub vs librosa 怎么选？"
```

### 模板 3：出错了先给上下文
```
❌ "报错了"
✅ "点浏览选文件后窗口卡死无响应，日志里没报错。是不是 get_audio_info 把整个文件加载到内存了？"
```

### 模板 4：不确定就先问
```
❌ "实现吧"（自己其实还没想清楚）
✅ "帮我头脑风暴一下，这个功能可能有几种实现方式？哪种最简单？"
```

## 对话中每一步在发生什么（这个项目的流程拆解）

### 阶段 1：设计（你不需要懂代码就能参与）
```
你说："我要做 XX 工具，用来 YY"
AI 问：输入格式？输出格式？GUI 还是命令行？参数默认值？
你答：根据自己需求选
AI 问：技术选型 A / B / C，我推荐 A
你答：可以 / 不行，选 B 因为...
AI：写设计文档
你：看一遍，有遗漏的补充
```
这个阶段不写一行代码，但做完后**整个软件要干什么、长什么样、用什么技术，全定好了**。

### 阶段 2：计划（AI 把大任务切成小任务）
```
AI：写实现计划，拆成 14 个任务
    任务 1：建项目骨架
    任务 2：写翻译模块
    任务 3：写设置模块
    ...
    任务 11：写主窗口
    任务 12：写入口文件
```
每个任务标注了：改哪个文件、调哪些接口、输出什么。**你不需要看代码，但可以看看顺序对不对**。

### 阶段 3：执行（一个一个来，出了错马上修）
```
AI：分派子代理做任务 1 → 做完 → 审查 → 通过 → 下一个
AI：任务 5 审查发现 bug → 修复 → 再审查 → 通过 → 下一个
```
**这个阶段你基本不用管**，AI 自己写代码、自己审查、自己修 bug。你只需要偶尔看看——有没有跑偏。

### 阶段 4：测试 & 踩坑（真机上跑才知道）
```
你：双击 exe 报错
AI：看日志，发现是 emoji 不兼容 → 换成纯文字 → 重新打包
你：启动太慢
AI：排查发现 Anaconda 的 MKL 占了 500MB → 切到 pip 版 numpy → 体积降到 22MB
你：处理文件时弹出 ffmpeg 黑窗
AI：加 CREATE_NO_WINDOW 标志 → 消除
```
**AI 猜不到的坑，全靠你在真机上跑出来**。这就是为什么不能 AI 写完就发——必须自己试一遍。

## 你什么时候需要介入？

| 场景 | 你该做什么 |
|---|---|
| AI 给了两个方案让你选 | 认真选，你的使用习惯只有你知道 |
| AI 问参数默认值 | 你设的值决定了用户体验 |
| 代码写完了 | 自己跑一遍，所有按钮都点点 |
| 打包成 exe 了 | 在另一台电脑上试试能不能跑 |
| AI 说"可以了" | 你说"再自查一遍代码，精简优化" |
| 准备发布 | 确认 README 写清楚了，zip 里文件不缺 |

## 三个坑（这个项目踩过的）

### 坑 1：AI 不知道你的实际运行环境
AI 在 macOS 上写的代码可能完全忽略 Windows 特有的问题：
- Emoji 在 tkinter 里炸了（Tcl 不支持 U+FFFF 以上字符）
- 中文 Windows 的默认编码是 GBK，ffprobe 输出 UTF-8 冲突
- 文件路径 `\` vs `/`

**对策**：写完就马上在自己电脑上跑。

### 坑 2：AI 的默认值可能不合适
AI 说"输出格式默认 WAV 吧"，你不会想到 WAV 占 5 倍体积。真跑起来才发现——处理完文件变大了。

**对策**：每个默认值都问一句"为什么是这个值？"

### 坑 3：AI 不知道什么该删
`.venv`、`build/`、`dist/`、`.idea/`、ffmpeg 二进制——AI 写代码时很顺手，但清理时容易忘。你第一次上传码云才发现仓库有四五百 MB 垃圾。

**对策**：上传前说"从根目录删掉所有用不到的，准备上传"。

## 下次你自己开一个新项目，怎么开始？

```
1. "我想做一个 XXX 工具，用于 YYY 场景"
   → AI 会反问：需求澄清

2. "我倾向于 A 方案，因为..."
   → AI 会写设计文档

3. "设计没问题，写实现计划"
   → AI 会拆成小任务

4. "一个一个实现"
   → AI 自动执行每步

5. "打包成 exe"
   → AI 帮你配 PyInstaller

6. "清理代码准备上传码云"
   → AI 帮你清理和推代码

7. "写个给新手的代码详解文档"
   → AI 帮你写教程
```

每一步都看懂了再下一步。**2000 行代码一口气看不懂，14 个小任务逐个别说——这就是这个项目教你的最重要的事情。**
